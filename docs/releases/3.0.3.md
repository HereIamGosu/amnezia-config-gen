# AmneziaWG Config Generator 3.0.3

## Endpoint Lab labels, phone badges and accessibility

Released on 2026-10-08 after 3.0.2 (`c4c6b67`).

A design and accessibility audit of 3.0.2 ([impeccable](https://github.com/pbakaus/impeccable) detector plus measurements in headless Chrome at 320–1440 px) found layout and legibility defects. This release fixes the ones confirmed in the browser.

## What changed for users

### Endpoint Lab

- "Check quality": at 768, 1280 and 1440 px the quality panel is narrower than the legend labels — "first session" ("с первой сессии") needs 102 px and got 74–97 px — and the label, kept on one line, ran into "after retry". The labels now wrap between words.
- The "being rechecked" tile of the pool summary is 117–123 px wide at 1280–1440 px, and the Russian label broke the word without a hyphen («перепроверк / е»). The label carries a soft hyphen and breaks as «пере- / проверке» in every browser, with or without a hyphenation dictionary.
- "Recent activity": the action word of an event was orange both for "restored" and for "temporarily excluded"; only the dot told them apart. The action now takes the colour of its dot: green for "restored" and "added to ACTIVE", amber for "sent for recheck" and "moved to reserve", light red for "temporarily excluded" and "removed from the pool".

### Generator

- Profile badges ("Recommended", "New generation", "Newest", "Legacy") were 9.5 px uppercase text on phones. They are 11 px, with slightly tighter letter spacing so the cards keep their layout at 320 px.
- "Reduce motion" in the system settings stopped every animation, including the loading spinner of the generate button; the button text is hidden while a config is generated, so the button showed a still ring. Decorative motion (the starfield, the floating illustration, dialog entrances) stays off; loading indicators — the generate spinner, status icons, the status refresh button and the "checking" dot — keep turning at 1.6 s per cycle.
- "Skip to generator", the first link for keyboard users, turned its text cyan on the orange background on hover, a 1.5:1 contrast; the text stays dark (≥ 4.5:1).

## AWG profiles and the API

No changes: `/api/*`, config generation, Lab Auto on the server and the invariants I1–I11 are the same as in 3.0.2.

## For developers

- Light status text colours are design tokens: `--color-success-text`, `--color-warning-text` and `--color-error-text` in `:root` of `public/static/styles.css` replace 27 raw values; the Lab tokens `--lab-ok`, `--lab-warn` and `--lab-error` alias them. The colours are unchanged.
- `e2e/design-floor.e2e.js` checks the fixes in the browser; `__tests__/design-tokens.test.js` keeps raw status shades out of the components.
- ESLint skips local `brag-output*/` folders (promo video builds, git-ignored), so `npm run lint` passes in a working copy that has them.

## For the operator

A push of the release to `main` deploys it (CI → GHCR → blue/green). No host, controller or Endpoint Lab change is needed. Smoke after the switch: `/`, `/en`, `/lab`, `/en/lab` answer with the release revision and asset version `?v=3.0.3`; the Lab summary and the quality legend render without overlapping text; no 5xx or restarts of the new slot. Rollback: `amnezia-deploy rollback` returns 3.0.2.

```bash
npm ci
npm run lint
npm test
npm run test:e2e
npm run evidence:check
npm run release:check
npm run seo:check
node scripts/check-asset-version-bump.js origin/main HEAD
git diff --check
```
