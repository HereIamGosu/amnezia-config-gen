# AmneziaWG Config Generator 3.2.4

## Cleaner page statistics: the generate button on screen, no event on every load

Prepared on 2026-11-15 after 3.2.3 (`e6a2065`, ledger commit `79f2f7d`). Nothing changes on the page for visitors except
the "Recent changes" entry, and config generation does not change: the server code (`api/`, `src/`, `server.js`) is that
of 3.2.0.

## What changed

**`generate_button_seen` (added).** The generate button sits below the first screen: 1.9–2.1 screens down on a phone
(390×844, 360×800) and 1.2 on a 1280×900 desktop, and about a fifth of new visitors never start a generation. The page
now sends one event per page load when at least half of the button is on screen (`IntersectionObserver`, threshold 0.5),
so a report can tell "did not reach the button" from "saw it and left". The event has no parameters. A browser without
`IntersectionObserver` sends nothing.

**`healthcheck_opened` (removed).** The event was sent from the page start-up code, on every load, so its Metrica goal
repeated the visit count: 7,335 of 7,549 users in 2026-11-08…11-14. The call and the name in the allowlist are gone.
Opening the status dialog is still counted by `status_modal_opened`.

No other event changes. No keys, addresses, presets or config text: every value still passes the allowlist of
`public/static/analytics.js`. The README list of tracked events now matches that allowlist.

## Checks

`npm test`, `npm run lint`, `npm run test:e2e`, `npm run seo:check`, `npm run release:check`, `npm run evidence:check`,
`node scripts/check-asset-version-bump.js 79f2f7d`. `__tests__/growth-button-seen.test.js` checks the allowlist, the

## Evidence boundary

The Metrica goal for `generate_button_seen` is created in the counter settings, not in this repository; Metrica does not
count a goal for the time before it exists. After this release the goal of `healthcheck_opened` (679532118) stops
receiving hits. Released while the 14-day reading of 3.2.1 and 3.2.2 (2026-11-08…11-21) is still open: the release
changes no element and no step of the page, and the metrics of that reading (start rate, `vpn://` copies, answers to
«Подключилось?», share clicks) do not use either event. No WARP registration was made for this release.
