## Protocol surface

`git diff b33a3b8 f57a9e3 -- api src server.js scripts deploy vercel.json` is empty: the handlers, the config builder
and the server runtime are those of 3.2.1, so the `.conf` text, its field order, AWG parameters, `I1`–`I5`, `AllowedIPs`
and the response fields cannot differ for the same request. No invariant test changed.

The advice the page gives is taken from the repository, not from upstream: the profile fallback follows
`src/server/clientCompatibility.js` (AWG 3.x needs an AWG 3.1-capable client; wg-tunnel accepts only AWG 1.5), and the
order of the steps follows the FAQ answer `faq_a5` (endpoint and port first, then the profile).
