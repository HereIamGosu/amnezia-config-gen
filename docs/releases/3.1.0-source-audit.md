## Protocol surface

| Surface | Change | Evidence |
| --- | --- | --- |
| I2–I5 for `cps5=1` (`src/server/cpsExtraPackets.js`) | Fixed random `<b>` bytes → runtime chains of `<b>`/`<r>`/`<t>`, a different shape per field | `__tests__/invariant-i9-cps5.test.js`; `IpcSet` on nine amneziawg-go revisions; live WARP handshakes with captured bursts |
| Own chains `i1`…`i5`, `cpsCompat` (`api/warp.js`, `public/static/cps-chain.js`) | New input; strict parser shared with the browser; 400 before WARP registration; gaps rejected | `__tests__/cps-chain.test.js`, `__tests__/cps-custom-chains.test.js`; 120 handler configs with own chains on nine revisions |
| `i1` in the body | Previously unchecked, now parsed (breaking for invalid input only) | `__tests__/cps-custom-chains.test.js` |
| Response | `appliedExtras.customCps` added; other fields unchanged | `__tests__/cps-custom-chains.test.js`, `__tests__/warp-contract.test.js` |
| Generation without own chains | Same keys, order and fixed fields as before | Oracle diff of 40 requests against the previous commit |

Upstream facts confirmed by source (amneziawg-go): tag set and per-send evaluation (`device/obf.go`, `obf_*.go`, `send.go` at `b5928ef`); `<rd>`/`<rc>` missing before v0.2.15 and `<r>` ≤ 1000 / single `<t>` up to v0.2.15 (`device/awg/tag_parser.go`, `tag_generator.go`); I-packets must be consecutive up to v0.2.15 (`device/awg/tag_junk_packet_generators.go`). Project policy: the automatic template uses `<b>`/`<r>`/`<t>` only.

Not verified: the client apps (AmneziaVPN, AmneziaWG, WG Tunnel) by hand, and networks with DPI.
