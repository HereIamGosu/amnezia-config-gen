# Release 3.2.1 — Source Audit

Checked on 2026-11-07 from `2c791ae` (one commit after the 3.2.0 release commit `0cd9312`). No upstream source was read:
the release changes only the page scripts (`public/static/script.js`, `result.js`, `analytics.js`, `metrika.js`,
`history.js`, `settings-link.js`) and two dictionary keys. The WireGuard/AmneziaWG wire format, AWG profiles, CPS,
`vpn://`, route presets and Endpoint Lab are untouched. The protocol evidence of [3.1.0](3.1.0-source-audit.md) is
unchanged; `npm run evidence:check` is part of the release checks.

## Protocol surface

`git diff 0cd9312 2c791ae -- api src server.js scripts deploy vercel.json` is empty: the handlers, the config builder
and the server runtime are those of 3.2.0, so the `.conf` text, its field order, AWG parameters, `I1`–`I5`, `AllowedIPs`
and the response fields cannot differ for the same request. No invariant test changed.
