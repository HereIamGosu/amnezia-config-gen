## Protocol surface

Unchanged: the `.conf` text, AWG profiles, CPS, I1–I5, routes, Lab. Changed: the packed JSON of `vpnLink` (more fields; `port` is a number; `hostName` from the Endpoint). Invariants I1–I11 pass; I10 is extended in the README and in its test.
