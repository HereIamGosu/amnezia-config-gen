## Protocol surface

Unchanged: the `.conf` text, AWG profiles, CPS, I1–I5, routes, `vpn://`, Lab. Only the set of accepted `warpPort` values changes: a value outside `PORT_ALLOWLIST` (2408, 500, 4500, 1701, 880, 8854) is refused with 400. Invariants I1–I11 are not touched; Lab Auto still changes only `Endpoint`, and the refusal comes before Lab selection.
