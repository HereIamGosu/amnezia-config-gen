# AmneziaWG Config Generator 3.0.2

## Endpoint Lab by default, iPhone dialogs, compatibility card

Released on 2026-10-07 after 3.0.1 (`e9c5605`).

## What changed for users

### Endpoint Lab is the default endpoint while its pool is fresh

The interface selects "Endpoint Lab — auto" when the Lab has fresh verified endpoints, the same state the "System status" card shows. While that is unknown, when the Lab has no fresh data and on deployments without the Lab, the hostname `engage.cloudflareclient.com` is selected and the note under the choice says why. A visitor's own choice — in the settings, in a settings link or with the error button — is never switched automatically.

If the Lab refuses a generation (`503 lab_*`), the error offers a "Generate with the hostname" button; the second request is sent only when it is pressed. The server stays fail-closed, and the API default stays the hostname. Settings links omit the endpoint while it is the default and carry an explicit choice, including the hostname.

### iPhone: dialogs close again

Some dialogs could not be closed on an iPhone. In Safari `100vh` is taller than the visible area, so a tall bottom sheet — the settings sheet was `92vh` — pushed its header with the close button above the screen, and a tap on the backdrop did not reach the page as a click. Dialog heights now follow the visible area (`dvh`), a dialog that does not fit keeps its top on the screen and the backdrop scrolls, and a tap on the backdrop closes the dialog.

### Compatibility card

After generation the card shows "Works" and "Uncertain" groups with app tiles — the AmneziaVPN and AmneziaWG app icons, monograms for other clients — with import formats and platforms, and "Not directly supported" as a collapsed list grouped by reason. One note replaces the repeated warnings; the AWG 3.1 client note appears only for AWG 3.x profiles.

### Phone layout and header

- Step 2 "Adjust parameters" starts expanded on a phone.
- "Community" opens a dialog with Telegram, GitHub and Discord; "Recent changes" opens a dialog with the release list.
- The header has no "GitHub" menu item; the GitHub icon next to the language switch, now also on phones, is the link.

### Fixed

- The Endpoint Lab quick view on the generator page requests the interface dictionary with the asset version, like the rest of the site.

## AWG profiles and the API

No changes: `/api/*`, config generation, Lab Auto on the server and the invariants I1–I11 are the same as in 3.0.1.

## For the operator

A push of the release to `main` deploys it (CI → GHCR → blue/green). No host, controller or Endpoint Lab change is needed. Smoke after the switch: `/`, `/en`, `/lab`, `/en/lab` answer with the release revision; in a fresh browser the generator selects Endpoint Lab while the Lab is healthy, the step-2 summary says the parameters are default, and the dialogs and texts render; no 5xx or restarts of the new slot. Rollback: `amnezia-deploy rollback` returns 3.0.1.

```bash
npm ci
npm run lint
npm test
npm run test:e2e
npm run evidence:check
npm run release:check
npm run seo:check
node scripts/check-asset-version-bump.js origin/main HEAD
git diff --check
```
