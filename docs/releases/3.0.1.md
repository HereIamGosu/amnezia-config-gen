# AmneziaWG Config Generator 3.0.1

## Interface texts after the update, Lab page fixes, status dialog

Hotfix for 3.0.0, released on 2026-10-07 after the 3.0.0 production rollout (`ea4f9dd`).

## What changed for users

### Texts instead of key names

After the 3.0.0 update some returning visitors saw key names such as `lab_state_ok_title` instead of texts on `/lab` and in the new parts of the generator. The interface dictionaries `/locales/ru.json` and `/locales/en.json` had no `Cache-Control` header and were requested at the same address in every release, so a browser that had loaded the 2.7.4 dictionary shortly before the update kept using it from its heuristic cache; that dictionary has none of the 480 strings added in 3.0.

3.0.1 requests the dictionary with the page asset version (`/locales/ru.json?v=3.0.1`) and serves it with `Cache-Control: public, max-age=0, must-revalidate`. The new address bypasses the old cached copy on the next page load; later releases change the address again, and the browser revalidates the file on every request.

### Endpoint Lab page

- "FAQ" and "История" in the header open the FAQ and the generation history dialogs on the Lab page; they no longer go to the generator page. The history dialog is the generator's: the list, the preview with the private key hidden, download and clearing.
- The footer is the generator's footer: FAQ, privacy, disclaimer and the donate link, with the same dialogs.

### Generator

- On desktop the page uses the same container width as the Lab page (1320 px).
- The "System status" dialog shows the rows of the status card in the hero — generator API, WARP registration, WARP endpoint, CIDR source and Endpoint Lab — with the host and response time, and a link to the Lab. The built-in list of WARP IP addresses stays at the end as reference information. The standalone `/status.html` page uses the same list without the Lab row.
- "Recent changes" lists the three latest releases, so the card keeps its height.
- The hero eyebrow reads «Бесплатный open-source инструмент»; the AWG 3.x note under the profiles has no "ℹ" sign.

## AWG profiles and the API

No changes: `/api/*`, config generation, Lab Auto and the invariants I1–I11 are the same as in 3.0.0.

## For the operator

A push of the release to `main` deploys it (CI → GHCR → blue/green). No host, controller or Endpoint Lab change is needed. Smoke after the switch: `/`, `/lab`, `/en/lab` answer with the release revision; `/locales/ru.json?v=3.0.1` answers with `Cache-Control: public, max-age=0, must-revalidate`; `/lab` in a fresh browser shows texts, the FAQ dialog opens on the page; one hostname generation. Rollback: `amnezia-deploy rollback` returns 3.0.0.

```bash
npm ci
npm run lint
npm test
npm run test:e2e
npm run evidence:check
npm run release:check
npm run seo:check
node scripts/check-asset-version-bump.js origin/main HEAD
git diff --check
```
